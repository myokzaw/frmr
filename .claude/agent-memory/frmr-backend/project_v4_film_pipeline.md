- applyStripLook(to:customization:outputWidth:) resizes+centre-crops to the slot first (resizedToSlot, Lanczos on clampedToExtent), then filters in a static RGBAh stripContext, renders RGBA8 sRGB. Off path returns the original UIImage (===).
- Film cube: FilmLUT.cachedCube keyed on profiles (Hashable), FIFO cap lutCacheLimit=8 (4 MB each at 64³). Colour cubes built from three 1-D tables; mono evaluates every lattice point (~70 ms debug sim). Mono renders use the red curve pair + monoWeights for all channels; balanced offsets solved on that pair.
- Curve-fitting finding: with display-referred input treated as scene exposure and x0 at mid grey, any logistic neg+print chain crushes shadows below ~20% sRGB and whites land ~220-235. Only fixable by moving x0/exposureScale off mid grey (spec forbids by default) — flagged under OPEN v4-5.
- FilmStock raw values are case names; v2 iso* values migrate via Constants.ImageProcessing.Film.legacyStockMapping; FilmStock has custom init(from:) applying the migration. AppEntry.init calls StripViewModel.migrateLegacyDefaults(.standard) because SettingsView binds @AppStorage to the raw string.
- Halation default must be read with object(forKey:) (missing key = on).
- Swift Testing print() output is not in xcodebuild stdout; StripRenderTimingTests writes /tmp/frmr-f1-timing.txt. Run it alone (-only-testing:frmrTests/StripRenderTimingTests) for a true cold number.
- F1 sim timings (4×12MP strip): before cold ~2.7 s / warm ~2.0 s; after cold ~0.45 s / warm ~0.1 s.
- Round 2 (F4–F6) Core Image gotchas: CIColorMatrix unpremultiplies, so an alpha-0 glow becomes black (use alpha 1 + linearDodgeBlendMode for additive light). CIRandomGenerator has random alpha: call settingAlphaOne(in:) before colour filters. Blend/compositing filters clamp negatives: keep grain intermediates positive (in·(1−a) + in·2a·n). CIColor(red:...) defaults to sRGB; use colorSpace: linearSRGB for linear test patches. Adding a blur branch can change half-float intermediates, so expect ±1 step pipeline differences, not bit-exact.
- Frontend runs UI tests on the same simulator; when both run, xcodebuild runs slow (10+ min). Use run_in_background + wait.
- Shadow fix (sample-sheet finding, OPEN v4-5): PrintProfile.blackTarget (lab 6, cinema 4, projection 3, matte 28 /255) via OutputNormalisation(sourceBlack,targetBlack,scale); per-channel ShadowToe below mid-grey pivot: S'(x)=a+(m1−a)t^n (n=Constants.shadowToeExponent=8), C1 at pivot, channel blacks keep their share of the neutral black (tint survives, luminance exact). Mid grey and above untouched. Separation 0.02–0.20 ≥0.77 of Off for all default prints.
- Fast curve iteration: swiftc -O -parse-as-library Constants.swift FilmModel.swift harness.swift (file must not be named main.swift) in scratchpad/harness.
- Sample sheets: TEST_RUNNER_FRMR_FILM_SAMPLES_DIR / _OUT env + -only-testing:frmrTests/FilmStockSampleSheetTests; DNGs in scratchpad/dng only. Lead sim 37A97720-…; "Busy preflight" launch error = simulator still booting, rerun after simctl bootstatus.
- F14 calibration: NegativeProfile.colour (ColourMatrix, rows sum 1: saturation/blueIntoGreen/redBlueCrosstalk) applied in linear before the curves; non-identity matrix forces full-lattice cube build (all three channels written). Cine teal shadows come from cinema print g+b Dmax 2.15 (cyan black share) + blue-steep crossover; red-steep crossover gave teal shadows but warm highlights, which broke existing "Cine highlights cool" tests. Per-stock GrainProfile (Constants.Film.Grain.standard/mono3200), grain curve data built per render. Negatives block regenerated by scratchpad/harness/negs.py (+ v3.py overrides).
